# モトリンク福岡｜ポートフォリオ第2作品

架空のバイクショップを題材にした日本語LP。Web制作と既存のAI FAQチャットを組み合わせた自主制作です。実際の店舗・販売・予約・問い合わせ受付は存在しません。

## 起動

ビルド・インストール不要です。`lp-motolink/index.html` をブラウザーで開くか、リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/lp-motolink/` にアクセスしてください。

## 実装

- HTML / CSS / Vanilla JavaScript。外部ライブラリ・外部フォント・ビルドツールなし。
- 店舗紹介、用途別バイクカテゴリー、点検・整備、利用の流れ、FAQ、相談導線。
- 760px以下のモバイルメニュー（開閉、リンク選択で閉じる、Escapeで閉じてボタンにフォーカス復帰）。JavaScript無効時もナビゲーションを表示。
- スキップリンク、フォーカス表示、セマンティックHTML、動きを減らす設定への対応。
- Difyへの外部リンクは新しいタブで開き、`noopener noreferrer` を指定。
- フォームや疑似送信処理なし。チャット部分は質問例のイメージであると明示。

## コンテンツと素材

住所・電話番号・価格・口コミ・販売在庫・店舗実績は掲載していません。車両はカテゴリーを表すイメージで、実在メーカーの車種ではありません。

`assets/mark.svg`、`assets/bike.svg`、`assets/ride.svg` はこの作品用にコードで作成したオリジナルSVGです。第三者の写真・ロゴ・アイコン・フォントは使用していません。これら3点は **CC0 1.0** で提供します（https://creativecommons.org/publicdomain/zero/1.0/）。他のファイルにライセンスを追加するものではありません。
