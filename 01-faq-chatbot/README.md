# 01 FAQチャットボット（Dify）

架空バイクショップのFAQに答えるチャットボットです。

## 目的
- 資料の範囲内の質問に正確に答える
- 資料にない質問には推測せず「分かりません」と答え、問い合わせ先を案内する

## 公開URL
https://udify.app/chat/2QqYFYd1MorRjoHf

## 構成
| 項目 | 内容 |
|---|---|
| 仕組み | Dify チャットフロー：ユーザー入力 → 知識検索 → LLM → 回答 |
| ナレッジ | faq-source.md を1問1チャンクで登録（区切り `###`、最大300文字） |
| faq-source.md | ボットの知識源（FAQ資料） |
| test-results.md | 想定質問50件のテスト結果（実施中） |
| demo.mp4 | 60〜90秒の操作動画（作成予定） |

## 使い方
1. 公開URLを開く
2. 質問を入力する（例：「営業時間は？」）

## 確認方法
- テスト50件：資料内 / あいまい / 資料外 / 誤答しやすい質問を含む
- 判定：正答 / 要修正 / 資料外
- 合格ライン：資料内質問への正答率 80%以上（修正後）
