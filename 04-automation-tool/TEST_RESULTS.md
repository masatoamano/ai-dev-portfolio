## サンプルからの出力

```text
python sales_summary.py samples/sales.csv -o examples/sales_summary.xlsx
完了: 7件 / 全体売上 26,400.6250
出力: examples/sales_summary.xlsx
```

生成物を再読込し、以下を確認しました。期待値はサンプルの数量×単価から算出した固定値と照合しています。

- 全体：7件、26400.6250
- 月別：1月9800、2月7500、3月9100.625
- 商品別：コーヒー8000、焼き菓子10800、マグカップ7500、茶葉100.625
- 月別・商品別・明細それぞれの合計と全体売上が一致
- 全体売上・月別売上・商品別売上・売上明細の4シート
- 小数付き金額が保存され、日付セル・数値セルとして読み取れる
- ZIPコンテナーに破損なし、数式セルなし

異常サンプルもCLIで実行し、2～4行目の計6項目のエラー、終了コード1、出力ファイルが存在しないことを確認しました。
