# 売上データ自動集計ツール

CSV・Excelの売上明細から、月別・商品別・全体売上を一度にExcelにまとめる、小規模事業者向けのローカルツールです。数量×単価の計算と集計表の作成を自動化します。作業時間の削減率は測定していません。

## 入出力のデモ

- 入力：[架空の売上7件](samples/sales.csv)（実在の顧客情報なし）
- 出力：[生成済みのExcel](examples/sales_summary.xlsx)
- エラー例：[修正練習用CSV](samples/invalid_sales.csv)
- プログラム：[sales_summary.py](sales_summary.py)

出力は「全体売上」「月別売上」「商品別売上」「売上明細」の4シート。見出しの色、金額の桁区切り・小数表示、日付形式、列幅、見出し固定、明細・集計のフィルターを設定しています。元データと集計値を照合できます。

| 月 | 売上金額 |
|---|---:|
| 2026-01 | 9,800.0000 |
| 2026-02 | 7,500.0000 |
| 2026-03 | 9,100.6250 |
| 全体（7件） | 26,400.6250 |

小数を含む計算を確認するため、架空の量り売り商品を含めています。金額の単位は入力に合わせます（複数通貨の混在は不可）。税・値引き・端数処理は加えません。

## Windowsでの使い方

1. [Python公式サイト](https://www.python.org/downloads/windows/)からPython 3.12以降をインストールします。Python Launcher（`py`）を含めてインストールしてください。
2. リポジトリをダウンロードして展開します。`04-automation-tool`フォルダーを開き、エクスプローラーのアドレス欄に `cmd` と入力してEnterを押します。以下は**コマンドプロンプト**用です。
3. 最初の1回だけ、次を1行ずつ実行します。仮想環境の有効化は不要です。

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. サンプルを集計します。

```bat
.venv\Scripts\python.exe sales_summary.py samples\sales.csv -o demo.xlsx
```

`完了: 7件 / 全体売上 26,400.6250` と表示されます。同じフォルダーの `demo.xlsx` をダブルクリックして確認してください（Excelなどの閲覧ソフトが必要です）。生成処理自体にMicrosoft Excelのインストールは不要です。

5. 自分のCSVをこのフォルダーに置き、ファイル名を差し替えます。空白のあるパスは引用符で囲みます。

```bat
.venv\Scripts\python.exe sales_summary.py "売上 2026.csv" -o "売上レポート 2026.xlsx"
```

Excel入力の例：

```bat
.venv\Scripts\python.exe sales_summary.py sales.xlsx -o report.xlsx
.venv\Scripts\python.exe sales_summary.py sales.xlsx --sheet "売上" -o report2.xlsx
```

複数シートがあるExcelでは、誤ったシートを集計しないよう `--sheet` が必須です。単一シートでは省略できます。`-o` を省略すると入力と同じ場所に `入力名_集計.xlsx` を作ります。**既存ファイルは上書きしない**ため、再実行時は出力名を変えてください。

### 入力のルール

1行目を次の4列・この順番にします。追加列・重複列は認めません。前後の空白は除去します。

```csv
取引日,商品名,数量,単価
2026-01-05,架空ブレンドコーヒー,10,500
```

- CSV：UTF-8（BOM有無とも可）、Shift_JIS系（CP932）。UTF-8→CP932の順に厳密デコードします。必要なら `--encoding cp932` / `--encoding shift_jis` / `--encoding utf-8-sig` を指定できます。
- Excel：`.xlsx`。1行目が見出し。日付はExcelの日付セル、または下記の文字列。数式は「コピー→値の貼り付け」で実数値に変えてください。
- 取引日：`YYYY-MM-DD` または `YYYY/MM/DD`。実在する日付のみ。時刻付き・単なる日付シリアル数値は不可。
- 商品名：1～100文字。改行・制御文字不可。同名商品のみ合算し、表記ゆれは自動統合しません。
- 数量・単価：0～999999.99、小数2桁まで。数量も小数可。負数・空欄・NaN・無限大・指数表記・通貨記号・桁区切りは不可。0は有効です。
- 空行もエラーになります。Excelの末尾の値のない追加列は書式だけの列として無視します。余分なデータ列はエラーです。

### エラーが出たとき

```bat
.venv\Scripts\python.exe sales_summary.py samples\invalid_sales.csv -o error_demo.xlsx
```

例：`CSV 2行目 [取引日]: 実在する日付を入力してください`。このサンプルでは6項目のエラーを表示し、出力を作りません。CSVは物理行番号（引用符内の改行があればそのレコードの開始行）、Excelはシート名・行番号を表示します。数式・Excelエラーセルではセル番地も表示します。見出しやファイル自体が不正な場合は、まずその問題を修正してください。

エラーが1つでもあると全体の集計を中止します。元ファイルを修正して再実行してください。正常終了は終了コード0、失敗は1です（引数の指定ミスは2）。エラーは標準エラー出力に表示します。必要ならコマンド末尾に `2> errors.txt` を付けて保存できます。

- `py` が見つからない：Python Launcherをインストールし、コマンドプロンプトを開き直す。
- `openpyxl` が見つからない：手順3のインストールを実施し、`.venv\Scripts\python.exe`で実行する。
- ファイルがない：このフォルダーで実行しているか、パス・拡張子を確認する。
- 出力先が存在する：別の出力名にする。入力・既存レポートは上書き不可。
- アクセス拒否：出力先の権限とExcelで開いているファイルを確認し、書き込み可能な場所と新しい名前を指定する。

## 設計と制約

- Python標準ライブラリと `openpyxl==3.1.5` のみを直接使用（openpyxlの間接依存はet-xmlfile）。初回インストール以外の通信、外部API、有料サービス、APIキーは不要。
- Decimalで乗算・集計し、独自の丸めはしません。出力は数式ではなく計算済み数値です。Excelの有効桁数を考慮し、全体売上を99999999999.9999以下（整数部11桁・小数部4桁）に制限します。超えた場合は出力せず、期間などでの分割を案内します。
- 入力は読み取り専用。出力は排他的に新規作成し、既存ファイルへの上書きを拒否します。書き込み途中の失敗時は今回の出力を削除します（OS強制終了や電源断を除く）。
- 数式の古いキャッシュ値を集計しないため、Excel入力の数式・エラーセルを拒否します。CSVの商品名が `=` で始まっていても、Excel出力では文字列として保存します。
- `.xls`、マクロ、パスワード付きExcel、列の自動対応付け、返品を表す負数、税計算・換算は対象外です。
- 入力全体をメモリーに保持するため、大規模データ向けではありません。性能や削減率は実測していません。
- Windows実機・Microsoft Excelアプリでの実行・表示確認は未実施。Linux上のPythonで処理を実行し、出力をopenpyxlで再読込して値・書式設定を検証しています。

Linux/macOSでは `python3 -m venv .venv`、`.venv/bin/python -m pip install -r requirements.txt` の後、`.venv/bin/python`で同じプログラムとテストを実行できます。
