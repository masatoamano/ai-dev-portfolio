# 検証チェックリスト v1

納品・公開前に、AI出力と制作物をこの順で確認する。
結果は「OK / NG / 対象外」で記録し、NGは重大度（致命的 / 重要 / 軽微）を付ける。

## 1. 事実確認
- [ ] 料金・営業時間・日付・数値が元資料と一致している
- [ ] 固有名詞（店名・商品名・地名・人名）の表記が正しい
- [ ] 元資料にない内容をAIが付け足していない（ハルシネーションなし）
- [ ] 資料外の質問に「分かりません」と答え、問い合わせ先を案内している

## 2. リンク
- [ ] すべてのリンクが開ける（404なし）
- [ ] リンク先が意図したページになっている
- [ ] 外部リンクは新しいタブで開く設定になっている（必要な場合）

## 3. フォーム
- [ ] 送信できる・送信完了の表示が出る
- [ ] 必須項目が空のときにエラーが出る
- [ ] メール形式の誤りにエラーが出る
- [ ] 送信内容が受信側に正しく届く

## 4. スマホ表示
- [ ] スマホ幅（375px前後）で横スクロールが出ない
- [ ] 文字・ボタンが小さすぎない／押しやすい
- [ ] 画像が崩れず表示される
- [ ] PC表示も崩れていない

## 5. 個人情報
- [ ] 実在の個人名・電話番号・メールアドレス・住所が入っていない
- [ ] APIキー・パスワード・トークンがファイルやリポジトリに入っていない
- [ ] スクリーンショット・動画に個人情報やキーが映っていない

## 6. ライセンス表記
- [ ] 画像・フォント・素材の出典とライセンスを確認した
- [ ] 必要なクレジット表記を入れた
- [ ] AI生成物であることを必要に応じて明記した
- [ ] 架空の店舗・サービスであることを明記した
